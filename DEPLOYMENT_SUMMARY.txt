HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. USER types payload in web interface
   Example: "Blood Pack O-Negative Emergency for trauma patient"

2. JAVASCRIPT detects priority in real-time
   → Matches keyword "blood" → Assigns P1-CRITICAL
   → Shows: "⚡ P1-CRITICAL — Life-threatening - Immediate dispatch"

3. USER clicks "Initiate UAV Launch"
   → Mission pushed to Firebase with auto-assigned priority

4. RASPBERRY PI daemon receives mission
   → rpi_receiver.py listens to Firebase
   → Adds to priority queue (P1 > P2 > P3 > P4)

5. UAV EXECUTES mission in priority order
   → Pi sends MAVLink commands to flight controller
   → Arm → Takeoff → Navigate → Deliver → RTL

6. TELEMETRY reported back
   → Pi updates Firebase with UAV status
   → Web interface displays live updates
