AUTOMATIC PRIORITY DETECTION KEYWORDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚡ P1-CRITICAL (Immediate dispatch - jumps queue):
  ✓ Blood: blood, blood pack, plasma, transfusion
  ✓ Organs: lung, kidney, heart, liver, organ, transplant
  ✓ Emergency Equipment: defibrillator, ventilator, crash cart
  ✓ Critical Meds: venom, anti-venom, epinephrine, naloxone
  ✓ Emergencies: emergency, critical, stat, code red
  ✓ Trauma: trauma, hemorrhage, cardiac arrest, stroke, anaphylaxis

🔥 P2-URGENT (Dispatch within 10 minutes):
  ✓ Time-sensitive Meds: insulin, diabetic, antibiotic, chemo
  ✓ Surgical: surgical, surgery, operation, scalpel
  ✓ Critical Supplies: oxygen, o2, oxygen cylinder
  ✓ Conditions: burn, fracture, seizure, asthma
  ✓ Keywords: urgent, asap, expedited

📦 P3-STANDARD (Default routine):
  ✓ Lab: lab samples, pathology, testing
  ✓ Medications: medication refills, prescriptions
  ✓ Supplies: bandages, syringes
  ✓ If no keywords match → defaults to P3

📋 P4-LOW (Batch when drone available):
  ✓ Admin: ppe, medical records, paperwork, documents
  ✓ Non-urgent: routine, non-urgent, batch, inventory

Example scenario with 1 drone:

Queue Status:
  #1: P1-CRITICAL   Blood Pack         🚁 ACTIVE (in flight)
  #2: P1-CRITICAL   Kidney Transplant  ⏳ QUEUED (next)
  #3: P2-URGENT     Insulin Kit        ⏳ QUEUED (#3)
  #4: P3-STANDARD   Lab Samples        ⏳ QUEUED (#4)

What happens:
1. Drone finishes Blood Pack delivery
2. Drone returns to base
3. Drone immediately takes Kidney Transplant (P1)
4. Insulin Kit (P2) waits for Kidney to complete
5. Lab Samples (P3) goes last

If NEW P1-CRITICAL arrives while drone busy:
→ Added to front of queue
→ Drone will take it next after current mission
→ All lower priorities wait
